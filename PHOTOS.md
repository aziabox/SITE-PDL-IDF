# Prises de vue à réaliser

Chaque emplacement ci-dessous attend une photo réelle prise sur le terrain.
Déposez le fichier dans `src/assets/photos/` sous le nom indiqué (`.jpg`, et si possible
`.webp` / `.avif` du même nom pour les formats modernes), puis relancez `npm run build`.
Le gabarit de réservation disparaît automatiquement dès que le fichier existe.
